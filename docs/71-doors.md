```
Archive.org Torrents → GitHub Actions Build → WASM Viewers → Static HTML
```

## WASM Viewers

Each door has:
- Rust WASM module (compiled in build)
- Prefetched data (from torrents)
- Static HTML interface
- WebGL/Canvas rendering

## Build Process

1. Download torrents (minimal, selective files)
2. Compile 71 WASM modules
3. Generate static HTML for each door
4. Create gallery index
5. Deploy to GitHub Pages
